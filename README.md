## ⚡ Quick Start

### 1. Download the Workflow
```bash
# Clone the entire repo
git clone https://github.com/bradleybeatz1313/free-n8n-paid-template-vault.git

# Or download individual workflow JSON files
```

### 2. Import to n8n
1. Open your n8n instance
2. Click **"..."** → **"Import from File"**
3. Select the `.json` workflow file
4. Configure your credentials

### 3. Customize & Activate
- Update any API keys or credentials
- Modify triggers to fit your needs
- Toggle the workflow **ON**
